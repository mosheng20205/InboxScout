## 拍之前必须过的三条

1. **涂掉真实隐私**：对端昵称、头像、私信正文里的人名/手机号/订单号，一律换成假值或打码。
   最稳的做法是先切到一个只有你自己测试号的账号再拍。
2. **别拿设计稿冒充实机图**：`ui-preview/` 那批是冻结评审稿，里面是**假数据**，不放进来。
3. **别在画面里露出凭据**：cookie 串、webhook key、代理账密、二维码原图（一张有效的 B站登录码
   等于一个待授权的会话入口）。截图里出现即作废该次登录，重扫一次。
